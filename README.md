# 🏔️ Learn Khowar: The Open Khowar Dictionary

Welcome to the open web home for learning and exploring Khowar, the core indigenous language of Chitral. Khowar is widely spoken across Chitral, Ghizer, Gilgit, Hunza, Baltistan, parts of the Wakhan, Vrang village of Tajikistan, many words of the language in Ladakh and Himachel Pradesh. This platform is designed for everyone children, students, native speakers, and AI/LLMs language learners worldwide to easily discover vocabulary, phrases, and cultural terms and help us develop or train this dictionary's engine and the data center.

---

## 🗣️ What is Khowar Language?

Khowar is a core distinct, ancient language (back dated 7,000 to 10,000 years ago) and the vibrant mother tongue of the Kho people. Rooted in the high Pamir mountains, Khowar boasts a rich oral tradition, timeless poetry, and vibrant folk folklore intimately connected to mountain culture and historical crossroads to Central Asian countries.

### Khowar Counting Engine & System

Khowar uses a **vigesimal (base-20) counting system**, where numbers build logically using multiples of **20 (`bishir`)** plus additions of **10 (`josh`)** and digits **1–9 (`e` to `neoof`)**. Beyond 100, numbers attach remainders using the conjunction **`oche`** ("and").

Because this follows a pure mathematical rule, thousands of static entries are not required for every single number. Instead, core base units are defined, and Khowar Counting Engine dynamically generates translations from **1 up to 100 Quadrillion (`shankh`)** and beyond.

#### Khowar Counting

You only need to store the core building blocks in your lexicon dataset:

```
  // Core Digits (1-10)
  "1": "e",
  "2": "ju",
  "3": "[tl]roi",
  "4": "chor",
  "5": "ponj",
  "6": "[ch]oi",
  "7": "so[tl]",
  "8": "osht",
  "9": "neof",
  "10": "josh",

  // Base Units & Scale Thresholds
  "20": "bishir",
  "100": "shor",
  "1000": "hazar",
  "100000": "lakh",                  // 100 Thousand
  "10000000": "khorur",              // 10 Million
  "1000000000": "arab",              // 1 Billion
  "100000000000": "kharab",          // 100 Billion
  "10000000000000": "neel",          // 10 Trillion
  "1000000000000000": "padam",       // 1 Quadrillion
  "100000000000000000": "shankh"     // 100 Quadrillion
```

## 🌟 Why Learn Khowar?

Khowar is a rich, expressive and symbolic language with a deep heritage tied to the music, poetry, war and polo traditions, and high mountain lifestyles of Central Asia.
